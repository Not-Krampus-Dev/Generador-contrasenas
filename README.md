# Generador de contraseñas

Generador de contraseñas simple hecho en Python.

## Características

- Permite elegir la longitud de la contraseña.
- Permite incluir números.
- Permite incluir símbolos.
- Valida las entradas del usuario.

## Tecnologías

- Python 3.10
- Librería `random`

## Uso

Ejecuta `main.py` y sigue las instrucciones que aparecen en la consola.
